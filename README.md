# CodeAlpha Java Gradle Project

A simple Java application built using Gradle as part of the CodeAlpha DevOps Internship (Task 3).

## Features
- Java application automated with Gradle
- Dependency management (Guava, Gson)
- Unit test using JUnit
- CI/CD pipeline using GitHub Actions

## How to Run
1. Clone the repo
2. Run: `./gradlew build`
3. Run: `./gradlew run`

## Technologies
- Java 21
- Gradle
- GitHub Actions
